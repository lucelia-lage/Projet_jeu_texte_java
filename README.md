Mini-jeu JavaScript (TD)

Description: 
Petit jeu interactif en console pour s'entraîner à utiliser les bases de JavaScript : conditions, boucles, et entrées utilisateur avec prompt-sync. 
L'utilisateur fait des choix qui influencent la suite de l’histoire.

Objectifs pédagogiques: 
- Manipuler les conditions if/else;
- Utiliser les boucles while;
- Gérer l’interaction utilisateur;
- Structurer un mini-scénario en code.

Améliorations possibles: 
- Organiser le code en fonctions pour plus de clarté; 
- Ajouter un système de points ou de scores;
- Créer une version web avec interface graphique.
